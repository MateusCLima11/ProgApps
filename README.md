# ProgApps

## COMANDOS BASICOS

   1) Trazendo  possíveis mudanças do Github:
   git pull

   2) Adionar arquivos para commit:
   git add .

   3) Criar versionamento (commit):
   git commit -m "comando basicos do git."

   4) Enviar alteraçoes para o Github:
   git push

   ## Branch 

   Mostrar branches no computador:
   git branch
